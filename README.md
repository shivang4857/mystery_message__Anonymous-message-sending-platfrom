# Mystery Message — Anonymous Message Sending Platform

An anonymous messaging platform built with **Next.js** where users can share a unique link and receive messages **without revealing the sender’s identity**.

🔗 **Live Demo:** https://mystery-message-anonymous-message-sending-platfrom.vercel.app

---

## ✨ Features

- 🔒 **Anonymous messaging** via shareable profile/message link  
- 👤 **Authentication** (NextAuth) for managing your inbox securely  
- 📬 **Receive & manage messages** (stored in MongoDB)  
- ✅ **Form validation** with Zod  
- 🎨 **Modern UI** using Tailwind CSS + shadcn/ui  
- ✉️ **Email support** (Resend) for verification/notifications (if configured)

---

##  Tech Stack

- **Frontend / Fullstack Framework:** Next.js (App Router), React, TypeScript  
- **Database:** MongoDB  
- **Auth:** NextAuth  
- **UI:** Tailwind CSS, shadcn/ui  
- **Validation:** Zod  
- **Email:** Resend
